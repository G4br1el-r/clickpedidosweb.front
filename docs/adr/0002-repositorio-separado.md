# Repositório próprio, fora do repositório da BetaUp

O front novo vive em `clickpedido-front`, com Git próprio (`github.com/G4br1el-r/clickpedidosweb.front`), e não como subpasta de `betaup.clickpedidoweb`. Foi decisão do dono do projeto: o novo front não pertence à BetaUp. O backend atual continua lá e é só referência de leitura (regras, cardápio, telas). Por isso as regras são portadas para `src/mock/regras/` com a origem citada, em vez de importadas.
